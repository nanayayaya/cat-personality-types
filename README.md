# 猫咪性格测试

这是一个基于科学评估的猫咪性格测试应用，旨在帮助猫咪主人更好地了解自己的猫咪性格特点。

## 特点
- 基于行为科学研究的测试设计
- 8种不同猫咪性格类型的详细描述
- 根据测试结果提供个性化建议
- 美观直观的界面设计

## 项目概述
基于猫咪性格五因素理论(Feline Five)构建的在线测试平台，类似于人类的16personalities测试，专为猫咪设计。目标是通过SEO获取自然流量，提供科学的猫咪性格评估系统。

## 核心功能需求

### 1. 四维评估模型
- **活跃性维度(Activity)**：
  - 参考密歇根大学2018年《家猫行为谱系研究》中运动量分级标准
  - 评估指标：日均活动时长、活动强度、探索行为频率
  - 极值分类：高活跃型(H) vs. 低活跃型(L)
  - 生理标记：肌肉张力、代谢水平、体脂率

- **社交性维度(Sociability)**：
  - 采用Lynch社交反应量表（SRQ-F），区分主动型/观察型互动模式
  - 评估指标：与人互动频率、与其他猫互动意愿、陌生人接纳度
  - 极值分类：外向型(E) vs. 内向型(I)
  - 生理标记：催产素水平、皮质醇波动范围

- **决策风格维度(Decision)**：
  - 结合威斯康星迷宫测试数据，设置"冲动型-审慎型"连续体
  - 评估指标：决策速度、风险承受能力、犹豫表现频率
  - 极值分类：果断型(T) vs. 观察型(P)
  - 生理标记：前额叶皮层活跃度、多巴胺受体敏感性

- **压力反应维度(Stress)**：
  - 使用FAST猫应激评估简版量表改编题目
  - 评估指标：环境变化适应能力、恢复平静所需时间、应激反应强度
  - 极值分类：高应激型(A) vs. 低应激型(C)
  - 生理标记：皮质醇分泌量、杏仁核激活阈值

### 3. 题目设计规范
开发20道强制选择题，每题包含：

- **前置信息收集**：
  - 家庭人猫比例（影响社交性评估权重）
  - 生活空间大小（影响活跃性评估标准）
  - 猫咪年龄（调整各维度标准曲线）
  - 是否多猫家庭（影响社交性指标评估）

- **题目结构**：
  - 情景化题干（如"新猫进入领地时的反应"）
  - 3-4个选项，每个选项对应不同的行为表现
  - 每个选项影响多个维度的分数（如选C项：活跃性+1，社交性-2）

- **动态计分规则**：
  - 基础分值：每个选项对四个维度有不同权重影响
  - 环境校准：根据前置信息动态调整得分权重
  - 一致性验证：设置镜像问题验证答案一致性

- **测试题目示例**：
  1. **家中来访客人时，您的猫通常会：**
     - A) 立即上前与客人互动 (活跃+2, 社交+2, 决策+1, 压力-1)
     - B) 保持距离观察一段时间后靠近 (活跃0, 社交+1, 决策-1, 压力0)
     - C) 躲藏直到客人离开 (活跃-1, 社交-2, 决策0, 压力+2)
     - D) 在房间内但保持安全距离 (活跃0, 社交-1, 决策0, 压力+1)

  2. **面对新玩具时，您的猫会：**
     - A) 立即扑上去探索并玩耍 (活跃+2, 社交0, 决策+2, 压力-1)
     - B) 谨慎接近，轻轻触碰后再决定 (活跃0, 社交0, 决策-1, 压力+1)
     - C) 完全不感兴趣 (活跃-2, 社交0, 决策0, 压力0)
     - D) 因害怕而躲避 (活跃-1, 社交-1, 决策-1, 压力+2)

### 4. SEO内容策略
在结果页嵌入可交互的"猫性格分布热力图"：

- **地理数据可视化**：
  - 调用Google Maps API显示用户地理定位
  - 根据地区显示不同猫咪性格类型的分布密度
  - 用户可查看全球/国家/地区性格分布趋势

- **SEO关键词优化**：
  - 对接SEMRush关键词数据库生成动态文案
  - 每个性格类型页面针对特定关键词优化
  - 利用结构化数据标记增强搜索引擎识别

- **社交分享功能**：
  - 生成定制化结果卡片，便于社交媒体分享
  - 嵌入分享统计，提高病毒传播可能性
  - 每个分享链接包含唯一标识符，便于追踪转化

- **内容扩展策略**：
  - 为每种性格类型创建专属内容页面
  - 提供猫咪性格相关的科学文章和研究
  - 开发"猫咪性格匹配"工具，帮助用户寻找与自己性格匹配的猫

## 技术实现方案

### 前端技术
- **框架**: Next.js（服务器端渲染有利于SEO）
- **样式**: Tailwind CSS
- **状态管理**: Redux

### 后端技术
- **API服务**: Next.js API Routes
- **数据库**: MongoDB

### 核心功能实现
- **测试引擎**: 基于权重算法的评分系统
- **视频集成**: Video.js，视频托管使用Cloudinary
- **地图热力图**: Google Maps JavaScript API集成

### SEO优化策略
- 服务器端渲染(SSR)
- 结构化数据标记
- 各猫咪类型的独立URL路径
- 关键词优化内容生成

### 运维部署
- **托管服务**: Vercel
- **CDN**: Cloudflare提升全球访问速度
- **监控**: Google Analytics和Search Console跟踪流量 

## 用户体验与增长策略

按AARRR漏斗模型（获客、激活、留存、变现、推荐）设计的可视化与交互方案：

### 1. 测试页动态效果
- **进度指示器**：
  - 采用「小鱼干收集」动画效果，每完成1题增加10%饱食度
  - 小猫形象随饱食度变化表情与动作（从饥饿到满足）
  - 完成测试时触发"吃饱喵"庆祝动画

- **选项交互体验**：
  - 选项悬停触发猫咪行为学Tips（如选B时显示"27%的布偶猫有此反应"）
  - 选择后显示微型猫咪行为动画，强化用户选择
  - 支持拖拽排序题型，提升用户参与感

- **状态管理与错误处理**：
  - 快速答题时弹出"喵~想清楚再回答哦"动效，附带猫爪按压效果
  - 答题矛盾时显示"猫咪性格再想想"提示，附带猫咪歪头动画
  - 自动保存功能，支持中断后继续测试

### 2. 结果页转化组件

#### 性格卡片组件
- **3D猫模型展示**：
  - 支持毛发质感切换（短毛、长毛、卷毛等）
  - 根据测试结果展示对应性格的肢体语言与姿态
  - 允许用户旋转360°查看模型细节

- **生存环境模拟器**：
  - 滑动查看该性格在都市/乡村环境中的适应性评分
  - 动态展示不同环境中该性格猫咪的行为特点
  - 提供个性化环境优化建议（如"建议增加高处休息区"）

- **基因类比模块**：
  - 显示"您的猫与豹猫相似度达62%"等野生猫科动物对比
  - 提供进化生物学解释（如"独立狩猎特性来源于非洲野猫"）
  - 展示同类型著名猫咪案例（如名人猫、电影猫角色）

#### 电商导流系统
- **智能推荐算法**：
  - 根据性格匹配猫玩具（如高活跃型推送自动激光笔）
  - 基于行为偏好推荐食品与用品（如独立型猫推荐智能喂食器）
  - 季节性产品匹配（如冬季为高应激型猫推荐加热垫）

- **饥饿营销组件**：
  - 显示"同类猫家长78%选择了这款爬架"社会证明
  - 限时优惠倒计时（"基于您猫咪性格的专属优惠"）
  - 库存紧张提示（"适合探险家性格的玩具仅剩3件"）

### 3. 社交传播机制
- **定制化分享内容**：
  - 生成「猫格鉴定书」精美图片模板（含二维码动态植入）
  - 提供多平台一键分享功能（微信、微博、Instagram等）
  - 支持添加个性化评论与猫咪照片上传

- **病毒式传播策略**：
  - 设计"测测你像哪种猫"人类对照测试，匹配主人与猫咪性格
  - "找到你猫的灵魂伴侣"功能，推荐与当前猫咪性格互补的品种
  - 地区性格排行榜（"查看您所在城市最常见的猫咪性格"）

- **社区互动机制**：
  - 创建基于性格类型的猫咪社群（如"探险家俱乐部"）
  - 定期推送性格相关的饲养技巧与训练方法
  - 用户可提交猫咪成长日记，展示性格发展轨迹
